# React + Vite
🚀 Возможности:
- Добавление новых дел
- Отметка выполненных дел
- Счетчик оставшихся дел
- Переключение между всеми делами, активными и выполненными
- Очистка выполненных дел
- Хранение данных в localStorage

🛠 Установка
Шаги:
- git clone https://github.com/diskaunt/todoList.git
- cd ваш-проект
- npm install

📚 Использование
- npm run start   # запуск проекта
- npm run build  # сборка проекта
- npm test      # запуск тестов
